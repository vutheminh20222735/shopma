# Client — M&A Shop (Angular)

Giao diện cửa hàng bằng Angular 19 standalone components.

- Điểm vào: `src/main.ts`, `src/index.html`
- Routes: `src/app/app.routes.ts`
- Trạng thái / API: `src/app/shop/shop.service.ts`, `src/app/shared/api.ts`
- Tính năng: `src/app/features/`
- CSS toàn cục: `src/styles.css`
- Ảnh tĩnh: `public/images/`

Dev: `npm run start` (proxy `/api` → cổng 3001). Build: `npm run build` → `dist/`.
