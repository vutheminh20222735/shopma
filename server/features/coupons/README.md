# Mã ưu đãi

Bộ xử lý API dưới `/api/shop/`: `coupon, coupons, coupons/{code}`. Điều phối qua `server/routes/shop.ts`; giao diện tại `client/features/coupons/`.

Schema liên quan: `database/schema/coupons.ts`.

Các file của tính năng:

- `api.ts`

Chạy và cài đặt bằng npm từ thư mục gốc có `package.json`; xem `HUONG_DAN_CHAY.md`.
