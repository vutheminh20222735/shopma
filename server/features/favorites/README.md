# Yêu thích

Bộ xử lý API dưới `/api/shop/`: `favorites, favorites/{id}`. Điều phối qua `server/routes/shop.ts`; giao diện tại `client/features/favorites/`.

Schema liên quan: `database/schema/favorites.ts`.

Các file của tính năng:

- `api.ts`

Chạy và cài đặt bằng npm từ thư mục gốc có `package.json`; xem `HUONG_DAN_CHAY.md`.
