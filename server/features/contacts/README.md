# Liên hệ và thông tin shop

Bộ xử lý API dưới `/api/shop/`: `settings`. Điều phối qua `server/routes/shop.ts`; giao diện tại `client/features/contacts/`.

Schema liên quan: `database/schema/contacts.ts`.

Các file của tính năng:

- `api.ts`
- `types.ts`

Chạy và cài đặt bằng npm từ thư mục gốc có `package.json`; xem `HUONG_DAN_CHAY.md`.
