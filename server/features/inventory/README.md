# Tồn kho

Bộ xử lý API dưới `/api/shop/`: `inventory, inventory/{id}`. Điều phối qua `server/routes/shop.ts`; giao diện tại `client/features/inventory/`.

Schema liên quan: `database/schema/inventory.ts`.

Các file của tính năng:

- `api.ts`
- `types.ts`

Chạy và cài đặt bằng npm từ thư mục gốc có `package.json`; xem `HUONG_DAN_CHAY.md`.
