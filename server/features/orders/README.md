# Đơn hàng

Bộ xử lý API dưới `/api/shop/`: `orders, orders/{id}`. Điều phối qua `server/routes/shop.ts`; giao diện tại `client/features/orders/`.

Schema liên quan: `database/schema/orders.ts`.

Các file của tính năng:

- `api.ts`
- `server/serialization.ts`
- `types.ts`

Chạy và cài đặt bằng npm từ thư mục gốc có `package.json`; xem `HUONG_DAN_CHAY.md`.
