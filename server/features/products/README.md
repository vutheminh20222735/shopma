# Sản phẩm

Bộ xử lý API dưới `/api/shop/`: `products, products/{id}`. Điều phối qua `server/routes/shop.ts`; giao diện tại `client/features/products/`.

Schema liên quan: `database/schema/products.ts`.

Các file của tính năng:

- `api.ts`
- `server/serialization.ts`
- `types.ts`

Chạy và cài đặt bằng npm từ thư mục gốc có `package.json`; xem `HUONG_DAN_CHAY.md`.
