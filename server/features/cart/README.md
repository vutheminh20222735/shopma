# Giỏ hàng và thanh toán

Bộ xử lý API dưới `/api/shop/`: `cart, cart/{id}; tạo đơn qua orders`. Điều phối qua `server/routes/shop.ts`; giao diện tại `client/features/cart/`.

Schema liên quan: `database/schema/cart.ts`.

Các file của tính năng:

- `api.ts`
- `server/cart.ts`
- `types.ts`

Chạy và cài đặt bằng npm từ thư mục gốc có `package.json`; xem `HUONG_DAN_CHAY.md`.
